## 它解决什么问题

上一轮刚理清项目结构、刚踩过一个坑、刚约定好怎么存文件——**新开一轮对话，它全忘了**。你只好再解释一遍背景，再传一遍文件，再提醒"别用中文文件名""密钥别写进日志"。时间花在重复交代上，而不是真正推进事情。

**Leo Agent System** 想解决的就是这件事：给 AI 一套**可带走的外置记忆和工作纪律**，让它在"会话结束、换对话、甚至换环境"之后，仍能较快回到状态。

它不是某个聊天产品的内置功能，而是一套**可移植的 skill / 工作区规范**：规则、经验、日志、文件放在固定目录里，用约定好的流程读写。对话会丢，文件不会；文件在，AI 就有机会"接着干"。

## 核心思路（四条就够理解）

1. **文件即记忆** —— 重要约定不写在聊天气泡里，写在工作区文档里。
2. **目录即分类** —— 稳定规则、长期知识、流水日志、媒体文件各有位置，避免一个大文件无限膨胀。
3. **日志即传承** —— 做完事要留下"做了什么、结论是什么"；可复用的再沉淀成经验条目。
4. **索引即导航** —— 记忆变大以后，先扫轻量索引，再定点打开某一段，避免每次把整本记忆塞进上下文。

另外还有一条贯穿始终的硬约束：**"宪法"文件（README）不能由 AI 私自改**；第一版会留一份永久快照（README1ST），防止规则被越改越歪，也方便你本地备份一份"根信任"。

## 工作区里大致有什么

不必一次记全，知道分工即可：

- **README.md**：规则总纲（环境、流程、命名、安全）——每次初始化先读
- **README1ST.md**：第一版宪法快照——不可删除的底层根逻辑
- **memory.md**：长期知识（技能、方法论、按主题归类的经验）
- **memory-index.md**：只做目录的轻量索引，方便快速查找
- **log-\*.md**：按时间段切开的流水账，默认不读，需要回溯再打开
- **file-tree.md**：自动生成的文件树，减少反复列目录
- **vault/**：密钥等敏感内容（与普通媒体目录隔离，文件树里自动隐藏）
- **pan/**、**code/**：媒体与脚本等资产

命名刻意做成**全英文核心文件名**，是为了避开中文路径、下载头编码一类真实坑——这是实战里磨出来的细节，不是装样子。

## 目录结构

```
leo/
├── README.md            # 宪法：规则、流程、安全规范。AI 不得私自改动，改动需二次确认。
├── README1ST.md         # 第一版宪法快照，永不删除，须本地备份。
├── memory.md            # 长期记忆：热缓存 + 技能库 + 按主题归类的经验库。
├── memory-index.md      # 轻量索引（仅目录），每次会话先读它。
├── file-tree.md         # 由 scripts/gen-filetree.py 自动生成。
├── vault/               # 敏感目录（文件树中隐藏）→ secrets.md
├── code/                # 辅助脚本（gen-filetree.py / vault_crypto.py）
├── pan/                 # 媒体：imga/ video/ audio/ document/
└── log-YYYY.MM.DD-YYYY.MM.DD.md   # 按周期归档的流水账。
```

## 手动安装

```bash
# 1. 把 skill 放到 agent 的 skill 根目录下，然后：
python3 scripts/scaffold.py /path/to/your-project

# 2. scaffold 会建好 leo/ 骨架、拷入空模板，并自动跑一次 gen-filetree.py。
# 3. AI 草拟首版 README.md（融合内核规则 + 平台规则 + 沙箱能力配置），
#    完整展示给你，**你明确确认后才落盘**。
# 4. 落盘的同时，逐字派生一份 README1ST.md。
# 5. 提醒你把 README1ST.md 备份到沙箱之外——它是根信任。
```

## 日常五步闭环

```
存文件 → 执行任务 → 更新索引与文件树 → 记录日志 → 大变动打包
```

其中最容易被偷懒省略、也最不能省的，是**写日志**——没有这一步，下一轮 AI 仍然像失忆。

## 安全模型

- **密钥只放 `vault/secrets.md`**，不在对话里原文复述，不写进 memory.md。
- **`vault/` 由脚本自动隐藏**，不出现在公开文件树。
- **可选加密保险库**（AES-256-GCM + PBKDF2，60 万次迭代）：默认关闭；启用需你额外二次确认。静态只存密文，passphrase 现场给、内存用、用完即弃。
- **平台安全分级必须声明**：
  - *私密沙箱*（只有你能读）：允许明文密钥，但仍建议加密。
  - *可分享沙箱*：禁止明文，必须启用加密保险库或外部密钥管理。
- **`README1ST.md` 不可触碰**：即使你后来要求删除，AI 也必须拒绝。

## 可选增强（默认全部关闭）

- **Cloudflare Tunnel**：反向出站长连接，无需公网 IP，把本地服务暴露到公网。
- **保活机制**：平台原生 cron / 心跳，防止空闲会话被杀。
- **自建文件服务器**：Caddy / `http.server` 交付大文件。
- **定时打包备份**：每日轻量包（规则+代码+vault），可直接喂给新会话快速恢复。
- **多工作区切换**：顶层索引 + 每个项目独立 `leo/` 树。
- **增量同步**：媒体用 `rsync` / `rclone`，规则代码用 `git`。

详细教程与踩坑记录见 `references/whitepaper.md`。
