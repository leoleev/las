# memory-index.md（记忆索引，仅目录 / TOC）

> 作用：memory.md 可能极庞大，AI 不应每次全量读取。本文件只提取「编号 | 关键词 | 归属 | 日期」，
> 控制在数 KB，确保会话初始化零负担。每次 memory.md 或 log 归档变动后同步更新本文件。

## 格式
`[编号] 关键词 | 归属文件/章节 | 日期`
- 技能/规则：`[S-xxx]` → memory.md §技能库
- 经验：`[E-xxx]` → memory.md §长期经验库/主题
- 流水账归档：`[L-周期]` → log-YYYY.MM.DD-YYYY.MM.DD.md

## 索引条目
（示例，正式使用请按实际填写并随变动维护）
```
[S-001] 示例技能 | memory.md §技能库 | 2026-10-28
[E-001] 示例经验主题 | memory.md §长期经验库/网络 | 2026-10-28
[L-2026.10] 10月流水 | log-2026.10.01-2026.10.31.md | 归档
```

## 维护提示
- AI 会话初始化先读本文件，按索引定点调阅，需要时才读 memory.md 对应章节或某个 log-*.md。
- 新增/归档后立即补一行；删除经验时同步移除对应行。
